# Nashriyot AI

Кичик нашриёт (1–5 ходим) учун ягона бошқарув тизими. Раҳбар ва ходимлар у билан Telegram орқали ишлайди. Координатор буйруқни босқичларга ажратиб, бешта AI агентга топширади. Барча натижалар битта базада сақланади, хавфли амаллар эса фақат раҳбар тасдиғидан кейин бажарилади.

- **Агентлар:** Координатор, Муҳаррир, Методист, Ишлаб чиқариш, Сотув, Молия.
- **Технологиялар:** Python 3.12+, aiogram 3, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL ёки SQLite, OpenAI (ихтиёрий), Docker.
- **Калитсиз ҳам ишлайди.** `BOT_TOKEN` бўлмаса, тизим demo режимга ўтади ва консолдан синалади. `OPENAI_API_KEY` бўлмаса, агентлар қоидалар асосида ишлайди.

## Telegram ботни улаш

1. @BotFather'да бот яратиб, токенни `.env` даги `BOT_TOKEN` га ёзинг.
2. Telegram ID'ингизни @userinfobot орқали билиб, уларни қуйидагиларга ёзинг:
   - `DIRECTOR_IDS` — раҳбар;
   - `STAFF_IDS` — ходимлар;
   - `VIEWER_IDS` — фақат кўриш ҳуқуқи.

   Бир нечта ID вергул билан ажратилади.
3. `python -m app.main` — миграцияларни қўллайди ва бот, API ҳамда автоматикани ишга туширади.
4. Ихтиёрий: `OPENAI_API_KEY` берилса, агентлар AI'дан фойдаланади. AI ишламай қолса, автоматик равишда қоида асосидаги режимга қайтади.

## Docker (сервер)

```bash

docker compose logs -f app
```

`docker-compose.yml` иккита хизматни ишга туширади:

Миграциялар ҳар ишга тушганда автоматик қўлланади. API портлари фақат `127.0.0.1` да очилади.

## Сотув агенти: Instagram, WhatsApp, Telegram ва телефон

Мижозларга ўзбек (лотин ва кирилл), турк ва рус тилида жавоб беради. Ҳар бир мижозни битта воронкадан ўтказади. Агент маҳсулот ҳам, хизмат ҳам сотади. Намуна каталог (`sales_catalog.example.json`) Туркия ва Ўзбекистон ўртасидаги хизматлар учун тузилган: Туркияда яшаш, иш ва ўқиш ҳужжатлари, турк фуқаролари учун Ўзбекистонда иш рухсати, Истанбул ва Самарқанд–Бухоро турлари, бизнес консалтинг ва консултация.

```
хизмат:  салом → хизмат, нарх ва ҳужжатлар → неча киши → исм → телефон → сана ва шаҳар → «ҳа» → ариза ✅
товар:   салом → маҳсулот ва нарх → нечта → исм → телефон → манзил (ёки «олиб кетаман») → «ҳа» → буюртма ✅
```

- **Хизмат номи мижоз тилида кўрсатилади:** турк мижоз «Özbekistan turu: Taşkent – Semerkant – Buhara», ўзбек мижоз «O'zbekiston turi» кўради.
- **Ҳужжатлар:** мижоз «qanday hujjatlar kerak», «hangi belgeler gerekli» ёки «какие документы нужны» деб сўраса, агент каталогдаги рўйхатни беради. Шу билан бирга «аниқ рўйхатни консултант тасдиқлайди» деб қўшади.
- **Нарх:** `"price_from": true` бўлса, нарх «150 $ dan» деб кўрсатилади ва якуний нархни консултант айтиши таъкидланади. Валюта USD, EUR, TRY ёки so'm бўлиши мумкин.
- **Кафолат йўқ:** агент виза ёки рухсатнома берилишини кафолатламайди ва қонун ҳақида ўзидан гап қўшмайди. Каталогда йўқ саволни консултантга ўтказади.

Каталогдаги хизмат майдонлари:
- `"kind": "service"`;
- `name`, `description`, `documents` ва `details_question` — тил бўйича (`{"uz": ..., "tr": ..., "ru": ...}`);
- `currency`, `price_from`;
- `"ask_quantity": false` — консултация каби хизматларда «неча киши» сўралмайди.

**Намунадаги нархлар ва ҳужжатлар рўйхати тахминий.** Уларни албатта ўзингизникига алмаштиринг.

**JIHAN JAN JASUR NAM TOUR MCHJ'нинг ҳақиқий каталоги** `sales_catalog.json` да. Унда учта хизмат бор:

| Хизмат | Нарх | Изоҳ |
|---|---|---|
| Паспортни текшириш (sorgulama) | 80 $ | натижа 12 соат ичида |
| Депортни олиб ташлаш (1 йилдан 5 йилгача) | 2 600 $ | олдиндан тўлов 600 $; «неча киши» сўралмайди |
| Туркияда ишлаш учун ҳужжатлар (иш берувчи орқали) | 800 $ | Vergi levhası, İmza sirküleri, Oda sicil kaydı, Son yılın gelir beyannamesi, İşletme belgesi — PDF (скан) ҳолида WhatsApp орқали |

Қўшимча майдонлар: `prepayment` — бир киши учун олдиндан тўлов, `result_time` — натижа муддати (тил бўйича).

- **Тил** мижознинг биринчи хабаридан аниқланади: «Salom, narxi qancha» → ўзбек лотин, «Нархи қанча» → ўзбек кирилл, «Fiyatı ne kadar» → турк, «Сколько стоит» → рус.
- **Нарх фақат каталогдан олинади.** Агент нарх, чегирма ёки бепул етказишни ўзи ўйлаб топмайди. Чегирма сўралса, «менежер алоҳида таклиф беради» дейди ва менежерга хабар юборади.
- Мижоз ҳаммасини бир хабарда ёзса («Namangan ertaklari 5 ta, ismim Ali, +998 93 555 44 33»), агент дарров кейинги қадамга ўтади. WhatsApp ва телефонда рақам ўзи маълум бўлгани учун сўралмайди.
- **Тасдиқдан кейин:** маҳсулот китоб бўлса, базада мижоз ва буюртма (`/orders`) яратилади. Менежерга Telegram'да тўлиқ карточка келади: канал, исм, телефон, маҳсулот, сумма, манзил.
- **«Оператор», «менежер», «odam bilan gaplashmoqchiman»** деб ёзилса, суҳбат менежерга ўтади. Шундан кейин бот жим туради, мижознинг хабарлари менежерга юборилади. `/lead bot <id>` суҳбатни яна ботга қайтаради.
- **OpenAI калити берилса,** AI жавобларни табиийроқ қилади ва эркин матндан маълумот олади. AI натижаси текширилади: каталогда йўқ маҳсулот, нотўғри сон ёки телефон қабул қилинмайди. Буюртмани фақат тизим тасдиқлайди. AI ишламай қолса, агент қоидалар асосида ишлашда давом этади.

Менежер буйруқлари (асосий ботда): `/leads` — охирги лидлар ва конверсия, `/lead <id>` — ёзишма. API: `GET /api/leads`.

### Сотувни ошириш

**1. Паспорт натижасидан кейинги таклиф.** Менежер натижани битта буйруқ билан юборади:
- `/result 12 ban 2023-йилдан, 5 йилга` — тақиқ бор;
- `/result 12 ok` — тақиқ йўқ.

Мижоз натижани олади ва кейинги хизмат таклифини кўради. Тақиқ бўлса, «Депортни олиб ташлаш — 2 600 $, олдиндан тўлов 600 $. Расмийлаштирамизми?» дейилади. Тақиқ бўлмаса, иш ҳужжатлари хизмати (800 $) таклиф қилинади. Мижоз «ҳа» деса, исм ва телефон қайта сўралмайди: агент тўғри тафсилот саволига ўтади. «Йўқ» деса, агент бошқа таклиф қилмайди.

Қайси натижадан кейин нима таклиф қилиниши каталогда `next_offers` майдонида ёзилади, масалан `{"ban": "deport", "ok": "ish-beruvchi"}`.

**2. Instagram изоҳлари.** Пост остига «нархи?» ёки «депорт қанча?» деб ёзилса, агент икки иш қилади:
- муаллифга Direct'да ўзи ёзади (Instagram'нинг private reply имкони билан);
- изоҳ остига қисқа жавоб қолдиради: «Жавобни Direct'га юбордик ✅».

«Зўр 👍» каби изоҳларга жавоб берилмайди (`SALES_COMMENT_MODE=intent`). Ҳамма изоҳга жавоб бериш учун `all`, ўчириш учун `off` қўйилади. Meta App'да webhook учун `comments` майдонига обуна бўлинг ва `instagram_manage_comments` рухсатини олинг. Instagram ҳар бир изоҳга фақат битта Direct хабарга ва фақат 7 кун ичида рухсат беради. Direct юборилмаса, агент изоҳ остида Direct'га ёзишни сўрайди.

**3. Билимлар базаси.** Агент фақат тасдиқланган жавоблардан фойдаланади:
- `sales_faq.json` — консултантлар тасдиқлаган савол-жавоблар уч тилда. Ҳозир унда натижа муддати, ҳужжатни қандай юбориш, депорт олдиндан тўлови, депорт муддатлари ва кафолат ҳақидаги жавоблар бор.
- Агент билмаган саволни менежерга юборади: «❓ Савол… /answer 12 матн». Менежернинг жавоби мижозга боради ва базага ёзилади. Кейинги мижоз шу саволни берса, агент ўзи жавоб беради.
- `/faq` — агент ўрганган жавоблар ва ҳар бири неча марта ишлатилгани. `/faq del 3` — нотўғри жавобни ўчириш.

### Каналларни улаш

Webhook'лар интернетдан HTTPS орқали очиқ бўлиши керак. Масалан, Caddy ёки nginx `https://ДОМЕН` → `127.0.0.1:8000` га йўналтирилади. Ҳар бир сўровнинг имзоси текширилади, имзосиз сўровлар рад этилади.

| Канал | Нима қилиш керак | `.env` |
|---|---|---|
| **Telegram** | @BotFather'да мижозлар учун иккинчи бот яратинг. Telegram Business бўлса, шу ботни Settings → Business → Chatbots'га уланг: бот дўкон аккаунти номидан ҳам жавоб беради | `SALES_BOT_TOKEN` |
| **Instagram** | Meta Developers'да App яратинг, Instagram professional аккаунтни уланг, `instagram_manage_messages` рухсатини олинг. Webhook: `https://ДОМЕН/webhooks/meta`, `messages` майдонига обуна бўлинг | `META_VERIFY_TOKEN`, `META_APP_SECRET`, `INSTAGRAM_ACCESS_TOKEN` |
| **WhatsApp** | Шу App'га WhatsApp Cloud API қўшинг, рақамни уланг. Webhook ўша `https://ДОМЕН/webhooks/meta` (`messages`) | `WHATSAPP_ACCESS_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID` |
| **Messenger** (ихтиёрий) | Facebook саҳифасини уланг, webhook ўша | `MESSENGER_PAGE_TOKEN` |

**Телефон ҳақида муҳим:** нутқни таниш ўзбек тилида ишлайди (`SALES_VOICE_STT_LANGUAGE=uz-UZ`, турк мижозлар учун `tr-TR`). Лекин Twilio'да ўзбекча овоз йўқ. Шу сабабли жавоб турк овози билан ўқилади (`SALES_VOICE_TTS_LANGUAGE=tr-TR`): у лотин ёзувидаги ўзбек матнини ўзбекчага энг яқин талаффуз қилади. Ҳақиқий ўзбекча овоз керак бўлса, ташқи TTS хизматини `<Play>` орқали улаш керак (ҳали қилинмаган).

**Meta чекловлари:** Instagram ва WhatsApp'да мижоз охирги марта ёзганидан кейин 24 соат ичида эркин жавоб бериш мумкин. Бу муддатдан кейин WhatsApp фақат тасдиқланган шаблон хабарларни юборишга рухсат беради. Агент фақат мижоз ёзганда жавоб беради, шунинг учун бу чекловга тушмайди.

## Хавфсизлик

- Рухсат Telegram ID бўйича текширилади. Роллар: раҳбар, ходим ва фақат кўриш ҳуқуқига эга кузатувчи. Ҳар бир рад этиш `audit_logs` га ёзилади.
- Токен ва калитлар фақат `.env` да сақланади. Ҳақиқий `.env` Git'га қўшилмайди. Улар `SecretStr` типида сақланади, логларда эса `***` билан яширилади: маълум қийматлар билан бир қаторда Telegram токени ва `sk-...` кўринишидаги калитлар ҳам яширилади.
- Тўлов, шартнома, оммавий хабар, чегирма ва нашрга якуний тасдиқ раҳбар қароридан кейингина бажарилади. Ҳар бир қарор `audit_logs` га фойдаланувчи ID, вақт ва қарор билан ёзилади. Бир сўров фақат бир марта бажарилади.
- Дубликатлардан икки қатлам ҳимоя қилади:
  - бир хил Telegram хабари хотирада ушланади ва иккинчи марта ишланмайди;
  - вазифа, буюртма, харажат ва тасдиқларда `idempotency_key` бор, у қайта ишга туширилгандан кейин ҳам сақланади.
- AI жавоби ишончсиз матн сифатида кўрилади. Ундан фақат текширилган JSON майдонлари олинади, агент номи рўйхат бўйича текширилади, жавобдаги кўрсатмаларга амал қилинмайди.
- REST API'да `/health` очиқ. `/api/*` эса фақат `X-API-Token` сарлавҳаси билан ишлайди. `API_TOKEN` берилмаса, `/api/*` ёпиқ туради.

## Автоматлаштириш

Фонда ҳар `SCHEDULER_INTERVAL_SECONDS` сонияда текширув ўтказилади:

- муддатга `REMINDER_HOURS_BEFORE` соат қолганда вазифа муаллифига эслатма юборилади;
- кечиккан вазифалар раҳбарга хабар қилинади;
- соат `DAILY_REPORT_HOUR` дан кейин кунлик ҳисобот юборилади.

Ҳар бир хабар фақат бир марта юборилади, қайта ишга туширилгандан кейин ҳам такрорланмайди. Буюртма ёки харажат ўзгарганда сотув ва молия кўрсаткичлари (`settings` жадвали) янгиланади. `/pause` ва `/resume` ҳамма автоматик жараёнларни ўчиради ва ёқади.

## Чекловлар (ҳали қилинмаган)

- **Ҳақиқий калитлар билан синалмаган.** Ҳақиқий Telegram токени ва OpenAI калити билан текширилмаган, улар мавжуд эмас эди. Бот сохта Telegram сессияси билан, OpenAI йўли эса сохта клиентлар билан тестланган.
- **AI'сиз агентлар оддий.** OpenAI калити бўлмаса, Муҳаррир ва Методист оддий қоидаларга таянади: тиниш белгилари, такрорлар, гап узунлиги. Тўлиқ имло луғати йўқ.
- **Фақат матн.** Қўлёзмалар матн сифатида қабул қилинади, DOCX ёки PDF файллари ҳали ўқилмайди.
- **Тасдиқдан кейин инсон бажаради.** Оммавий хабар тасдиқланганда мижозларга автоматик юборилмайди, тўлов эса банк орқали амалга оширилмайди. Бу ишни масъул ходим бажаради, тизим фақат қарорни қайд этади.
- **Сотув агенти ҳақиқий Meta/Twilio калитлари билан синалмаган.** Webhook'лар Meta ва Twilio ҳужжатларидаги намуна сўровлар ва имзолар билан тестланган.
- **Стикер ва видео ўқилмайди.** Видео ҳужжат сифатида сақланади, лекин агент унинг мазмунини тушунмайди.
- **Фақат polling режими.** Бот Telegram'га polling орқали уланади, webhook ҳали йўқ.
- **Битта ишчи жараён.** Тизим битта жараён сифатида ишлашга мўлжалланган. Хотирадаги такрорий хабарлар рўйхати қайта ишга туширилганда тозаланади, лекин базадаги `idempotency_key` ҳимояси қолади.
